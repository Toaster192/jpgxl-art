ArtXL — mutate & generate JPEG XL art

JPEG XL allows for beautiful, sub-100-byte images, but writing one by hand is fiddly. This playground makes it easier by generating new art from scratch and applying mutations to existing programs, exploiting JPEG XL's tree-shaped (code-like) representation. What is JPEG XL art? · Syntax reference

Want to write the code by hand instead? These editors are great for that: Luca Versari, qon, Januschka, Surma.
